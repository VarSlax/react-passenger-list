# ✈️ Passenger Hub

A modern, accessible React application for managing passenger lists. Built with speed and visual excellence in mind.

## 🚀 Features

- **Dynamic Fetching**: Automatically pulls real-looking passenger data from the [RandomUser API](https://randomuser.me/).
- **Manual Management**: Add your own passengers to the list with instant UI updates.
- **Premium Design**: Sleek glassmorphism UI with smooth animations and responsive layout.
- **Accessibility First**: Fully semantic HTML structure with ARIA labels and focus management.
- **Modern Stack**: Powered by React 18, TypeScript, and Vite for a lightning-fast development experience.

## 🛠 Tech Stack

- **Framework**: React 18 (TypeScript)
- **Build Tool**: Vite
- **Styling**: Vanilla CSS (Custom UI kit)
- **Routing**: React Router 6
- **Linting**: ESLint + Biome

## ⚡️ Quick Start

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run dev server**:
   ```bash
   npm run dev
   ```

3. **Build for production**:
   ```bash
   npm run build
   ```

## 📂 Project Structure

- `src/components`: Reusable UI components.
- `src/pages`: Main application views (Home, Passenger List).
- `src/types`: TypeScript interfaces for API and state.
- `src/assets`: Static assets and icons.
- `src/hooks`: Custom React hooks.
